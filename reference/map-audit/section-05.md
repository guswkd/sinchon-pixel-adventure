# 05 캠퍼스 북쪽과 서쪽 확장

2026-10-22. 저장된 CITY_GEOGRAPHY의 도로·건물 외곽을 사용하여 북쪽 경계를 25에서 -45, 서쪽 경계를 145에서 115로 확장했다. 새 조사나 임의 건물 배치는 하지 않았다. 총 553개 건물, 628개 도로 객체, 방문 지점 15곳이다. 서쪽 확장은 기존 구간에도 적용된다. 외관 미확인 건물은 기본 모델이며 북쪽 캠퍼스 전체를 재현한 것은 아니다.

05 구간은 A~D로 나누어 전체 작업 구역은 20개다. 백양로 북쪽 (291,-25), 스포츠과학관 주변 (169,20)은 지상 산책용 방문 지점이며 출입문 실측 좌표가 아니다. 내부 및 지하는 포함하지 않는다.

카메라: 게임은 StableCamera를 사용한다. 기본은 북쪽 고정이며 도로 선택·골목 왕복·진행 방향으로 회전하지 않는다. Q/R은 수동 회전 후 유지, C는 북쪽 기준 복귀, 역 앞으로는 북쪽 초기화. 기존 RouteCamera는 비교용 회귀 테스트에만 남아 있다.

검증: 전체 15개 지점 접근성, 기존 충돌·다리 통행, 새 05 경계, 골목 왕복과 역순 경로의 동일 시점, 수동 회전 유지 및 북쪽 복귀 테스트.
