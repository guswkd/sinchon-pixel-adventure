# 04 구간: 백양로 · 공학관 · 백주년기념관 앞

2026-10-22, 3D 산책 버전 확장.

- 범위: x=145…350, y=25…616. 이전 북쪽 경계 y=145에서 연속 확장했다.
- 저장된 지도 기준 건물 외곽 467개, 도로 객체 537개. 이전보다 각각 26개, 114개 늘었다.
- 백양로 way 123432894의 원래 선형과 주변 보행로·녹지 다각형을 사용한다.
- 제1공학관 205583531, 제4공학관 553898005, 백주년기념관 324328422 등 기존 건물 외곽을 보존한다.
- 공학관 앞 (245,113), 백주년기념관 앞 (281,86), 백양로 산책길 (272,43)을 게임용 방문 지점으로 추가했다. 실제 출입문 좌표를 뜻하지 않는다.
- 총 13곳을 신촌역에서 걸어갈 수 있다. 건물 내부와 백양누리·지하 연결은 이번 범위에 포함하지 않는다.

좌표 출처는 `assets/city-geography.js`와 `reference/sinchon-osm.xml`이다. 이전 구간에서 대조한 [연세대 오시는 길](https://www.yonsei.ac.kr/sc/502/subview.do), [신촌캠퍼스 소개](https://yonsei.ac.kr/sc/662/subview.do)의 캠퍼스 방향을 유지한다. 이번에 모든 외관을 새로 로드뷰 조사한 것은 아니다. 건물 높이·색·벽면·표지와 나무는 게임용 표현이다.

검증: 모든 방문 지점 연결성, 03–04 경계, 실제 백양로 선형 왕복 이동, 자동 시점 및 기존 조작·충돌 회귀 테스트 통과. 브라우저에서 신촌역부터 공학관과 북쪽 산책 지점까지 직접 이동하고 안내 대화를 확인했다.
