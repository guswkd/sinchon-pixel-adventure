# 03 구간: 성산로 횡단 · 연세대 정문 · 백양로 초입

2026-10-21, 3D 산책 버전 확장.

- 열린 범위: x=145…350, y=145…616. 기존 북쪽 경계 y=258을 넘어 정문과 백양로 초입까지 연속 이동한다.
- 저장된 OSM 자료의 441개 건물 외곽, 423개 도로 객체를 포함한다. 새 건물 외곽이나 직선 연결 도로를 임의로 만들지 않았다.
- 정문 위치: OSM node 5799952872, (235,189), 위도 37.5604517 / 경도 126.9368064.
- 성산로 횡단보도: way 1182081723 및 인접 crossing 객체. 대각선·직선 횡단보도를 원래 좌표 그대로 표시한다.
- 백양로: way 123432894. 북쪽으로 향하며 동쪽으로 기우는 기존 보행로 선형을 사용한다.
- 정문 광장: pedestrian area 675327874. 캠퍼스 녹지도 저장된 다각형을 사용한다.
- 공학원: building 218430716. 의료원 측 연세암병원: building 473006252.
- 방문 지점은 성산로 횡단보도, 연세대 정문, 백양로 초입을 더해 총 10곳이다.

공식 위치와 캠퍼스 동선은 [연세대학교 오시는 길](https://www.yonsei.ac.kr/sc/502/subview.do)과 [신촌캠퍼스 소개](https://yonsei.ac.kr/sc/662/subview.do)를 대조했다. 도로·정문 세부 좌표는 기존 `assets/city-geography.js` 및 `reference/sinchon-osm.xml`을 따른다.

건물 높이·벽면·표지·나무·보행로 표시 폭은 게임용 표현이다. 현재 모든 시설의 외관을 로드뷰로 재조사한 것은 아니다. 정문을 가로막는 임의 아치나 충돌벽은 추가하지 않았다. 캠퍼스 깊숙한 구간, 건물 내부, 지하 연결은 이번 확장에 포함하지 않는다.

검증: 신촌역에서 10개 방문 지점까지 연결성, 실제 횡단보도 선형과 정문 진입로 양방향 통과, 백양로 자동 시점, 기존 달리기·직진·교량 통과 회귀 테스트. 브라우저에서 신촌역→성산로→정문→백양로 초입을 직접 이동하고 정문 대화를 확인했다.
