# 건물 상세화: 01-A U-PLEX

2026-10-22. 기존 01~04 구간을 각각 A(북서), B(북동), C(남서), D(남동)로 분할한 16개 작업 구역. 경계는 작업 관리용이며 실제 행정구역이나 길을 뜻하지 않는다. 건물 외곽·통행 경계는 유지한다. 다음 작업은 01-A 주변 상가 조사, 01-C 현대백화점 본관 순으로 진행한다.

## 이번 반영

- U-PLEX OSM way 356392577. 기존 다각형과 출입구 조사 자료 유지.
- 설계사 해안건축: 지상 12층 / 지하 7층. https://m.haeahn.com/en/project/detail.do?prjctSeq=624
- 현대백화점 현재 안내: 1F~12F 및 13F SKY GARDEN. 옥상정원을 추가 실내 한 층으로 만들지 않았다. https://ehyundai.com/newPortal/uplex/DP/FG/FG000000_V.do?branchCd=B00127100
- 높이 60m는 저장된 `uplex.osm`의 height 태그. 건축 도면 실측치로 검증된 것은 아니다. 같은 수평 축척(0.42/1.5)을 적용하여 장면 높이 16.8로 표현한다.
- 해안건축 외관 사진을 직접 대조했다. 청색 유리 커튼월, 세로 프레임, 저층 돌출부, 상층 로고 및 옥상정원을 단순화한다. 전광판 이미지는 게임용 자체 도형이다. 프레임 간격·돌출 깊이·정원 내부는 실측이 아니다.
- 사진: https://m.haeahn.com/upload/prjctmain/20150113174740155894.jpg
- 지하 7층은 건축 규모 정보이며 지하 공간을 새로 구현했다는 뜻이 아니다. 공식 영업 안내에는 공개된 B1~B5만 나온다.

## 검증과 남은 작업

16개 구역 분할, U-PLEX 12층/높이 환산, 기존 전체 길 연결·교량 아래 왕복 충돌·카메라 테스트 통과. 유플렉스 주변 직접 달리기 및 회전 시점 확인.
다른 건물은 미검증 기본 모델을 유지한다. `prototype/building-survey.mjs`에 출처가 확인된 건물만 추가하는 방식으로 진행한다. 모든 주변 건물이 실제 층수로 수정된 상태가 아니다.
