# 신촌 지도 대조 — 2026-10-17

Google 지도에서 신촌역–연세로–명물길, 현대백화점·U-PLEX 주변 블록, 성산로–연세대 정문–백양로를 육안 대조했다. 주요 지점은 OpenStreetMap API에서 현재 좌표를 별도로 받아 저장된 원본 및 게임 좌표와 비교했다. 로드뷰로 모든 건물 외관을 확인한 검사는 아니다.

`python3 tests/geography.test.py`는 내려받은 공개 지도 노드에서 독립적으로 투영한 좌표와 생성된 데이터의 오차를 확인한다. 14개 지점은 기준 타일 오차 1.1m 이내다. 본관과 U-PLEX의 모든 경계 선분이 현재 OSM 경계와 일치하는지도 검사한다.

`node tests/game.test.cjs`는 실제 플레이 지도에서 빨잠·입구 좌표, 입구 양방향 도착 지점, 전체 보행 접근성, 연세로–명물길–정문 연결, 입력 및 저장 복원을 검사한다. 지도가 보정되어 저장 위치가 건물 안이 되면 기념품·스탬프를 유지하고 보행 가능한 위치로 옮긴다.

## 검증 범위의 한계

이 검사는 측량 지도 전체의 정확성을 보증하지 않는다. 도로 폭·보도 폭은 도로 종류에 따른 게임용 근사이고, 건물 외관은 창작 도트다. 이번에 최신 OSM API와 직접 대조한 건물 경계는 현대백화점 본관과 U-PLEX다. 다른 건물은 보존된 OSM 스냅샷을 사용한다.

지하철 대합실·승강장과 백화점 B1·B2의 세부 통로 길이, 매장 위치는 실제 실내 평면도를 확보하지 못해 게임용 도식으로 유지했다. 공식 안내로 확인한 것은 신촌역 1번 출구 내부와 백화점 B2의 연결 관계다.

## 후속 수정: 지상 입구와 지하 통로의 구분

앞선 검사의 ‘현대백화점 지하통로’ 좌표 자체는 맞았지만, 그 노드가 **지하 출입문**이라는 의미를 놓쳤다. 이 노드를 지상 계단으로 사용했던 구현과 위 표의 해석을 정정한다.

2026-10-17에 OSM `map?bbox=126.9354,37.5546,126.9379,37.5572`를 받아 `underground.osm`에 저장했다. `scripts/build-underground.py`는 여기서 19개 복도와 48개 노드를 추출하며, 지상과 동일한 북쪽 방향·1.5m 격자를 사용한다.

- 신촌역 1~8번 출구의 **지상 계단 입구와 지하 계단 끝**을 각 steps way의 양 끝으로 구분했다. 지하 위치를 지상 위치의 37.5%로 축소하던 계산을 없앴다.
- node 2364556158은 역–본관 사이의 지하 연결문으로만 사용한다. 지상에는 실제 계단 way 1436163453의 지상 끝 node 13200578591을 사용한다.
- 빨잠 출구 node 12557603701과 지하 에스컬레이터 끝 node 13185495411을 연결한다. 별도 U-PLEX 건물 출입문 node 13200478453 → 로비 → node 13200478454 계단 → node 13206248860 지하 착지 → 본관 연결 복도를 추가했다.
- 지상–지하 맵을 옮길 때 복도의 방향과 길이가 바뀌지 않도록 좌표 원점만 이동한다. 통로 폭은 보행을 위한 근사다.
- 도착한 계단의 옆 칸을 밟아 즉시 원래 맵으로 튕기는 문제를 막았다. 계단을 벗어난 뒤 재진입하면 정상 작동한다.
- 이전 실내 저장 좌표는 새 지도에서 다른 장소를 뜻하므로 실내 입구로 복원하고 기념품·스탬프는 보존한다.

### 공식 도면과 OSM 층 표기 충돌

[현대백화점 신촌점 공식 층별 안내](https://www.ehyundai.com/newPortal/DP/FG/FG000000_V.do?branchCd=B00127000)의 ‘층 안내도’를 브라우저로 열어 B2 본관, 긴 연결 복도, U-PLEX 측 구역을 직접 확인했다. B1 식품관 도면도 비교했다. B2 안내에는 본관–U-PLEX 연결 복도와 U-PLEX의 ‘올리브영 오픈 준비 중’ 구역이 표시된다. B1은 별도 식품관이다.

OSM way 1434541117의 이름은 ‘지하 1층 통로’지만 `layer=-1`은 백화점의 층 번호를 보증하지 않는다. 이 구현은 **평면 경로는 OSM, 본관 연결층의 명칭은 공식 B2 안내**를 따른다. 빨잠–건물 로비의 세부 단차는 OSM 계단 연결 관계를 사용한다. 내부 매장의 정확한 경계, 각 계단의 높이 및 층 간 단차 전체를 실측한 것은 아니다.

역은 확인된 출구 대합실과 공용 연결통로를 구현한다. 이전의 임의 매표소·개찰구·선로 배치를 제거했다. 실제 승강장이나 유료구역의 평면도를 확보한 것으로 표현하지 않는다. 본관 매대와 B1↔B2 에스컬레이터의 세부 위치는 게임용 근사이며 공식 도면의 모든 매장 구획을 복제한 것이 아니다.
