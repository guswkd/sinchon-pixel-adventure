# 신촌 지도 대조 — 2026-10-17

Google 지도에서 신촌역–연세로–명물길, 현대백화점·U-PLEX 주변 블록, 성산로–연세대 정문–백양로를 육안 대조했다. 주요 지점은 OpenStreetMap API에서 현재 좌표를 별도로 받아 저장된 원본 및 게임 좌표와 비교했다. 로드뷰로 모든 건물 외관을 확인한 검사는 아니다.

## 확인한 자료

- [신촌역–연세로 지도](https://www.google.com/maps/@37.5576,126.9368,17z), [U-PLEX 주변](https://www.google.com/maps/@37.5568,126.9366,19z), [연세대 정문](https://www.google.com/maps/@37.5604517,126.9368064,18z)
- `nodes.osm`: 신촌역 출구 8곳, 현대백화점 지하통로·빨잠·빨잠 출구·홍익문고·연세대 정문·연세로사거리 6곳. 현재 OSM 좌표와 저장된 원본의 좌표 차이는 모두 0m였다.
- `hyundai.osm`: [현대백화점 본관 relation 19696463](https://www.openstreetmap.org/relation/19696463). 현재 경계 노드와 멤버 연결은 저장된 원본과 같았다.
- `uplex.osm`: [U-PLEX way 356392577](https://www.openstreetmap.org/way/356392577). 현재 외곽선은 저장된 원본과 같았다.
- [현대백화점 공식 오시는 길](https://www.ehyundai.com/newPortal/DP/WC/WC000000_V.do?branchCd=B00127000): 신촌역 1번 출구 내부에서 B2로 연결됨을 재확인했다.

OSM 스냅샷은 https://api.openstreetmap.org/api/0.6/ 의 `nodes?nodes=…`, `relation/19696463/full`, `way/356392577/full`에서 받았다. 지도 데이터 © OpenStreetMap contributors, ODbL 1.0.

`python3 tests/geography.test.py`는 내려받은 공개 지도 노드에서 독립적으로 투영한 좌표와 생성된 데이터의 오차를 확인한다. 14개 지점은 기준 타일 오차 1.1m 이내다. 본관과 U-PLEX의 모든 경계 선분이 현재 OSM 경계와 일치하는지도 검사한다.

`node tests/game.test.cjs`는 실제 플레이 지도에서 빨잠·입구 좌표, 입구 양방향 도착 지점, 전체 보행 접근성, 연세로–명물길–정문 연결, 입력 및 저장 복원을 검사한다. 지도가 보정되어 저장 위치가 건물 안이 되면 기념품·스탬프를 유지하고 보행 가능한 위치로 옮긴다.

## 검증 범위의 한계

이 검사는 측량 지도 전체의 정확성을 보증하지 않는다. 도로 폭·보도 폭은 도로 종류에 따른 게임용 근사이고, 건물 외관은 창작 도트다. 이번에 최신 OSM API와 직접 대조한 건물 경계는 현대백화점 본관과 U-PLEX다. 다른 건물은 보존된 OSM 스냅샷을 사용한다.

지하철 대합실·승강장과 백화점 B1·B2의 세부 통로 길이, 매장 위치는 실제 실내 평면도를 확보하지 못해 게임용 도식으로 유지했다. 공식 안내로 확인한 것은 신촌역 1번 출구 내부와 백화점 B2의 연결 관계다.
