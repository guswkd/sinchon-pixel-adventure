# 02 구간: 연세로 북쪽 · 명물길

2026-10-20, 3D 산책 버전 확장.

- 열린 범위: 기존 역–현백–U-PLEX에서 연세로 북쪽·명물길 1차 구간·창천교회 앞까지.
- 동일 좌표계의 저장된 OpenStreetMap 도로/건물 경계를 사용한다. 새로운 사각형 건물이나 임의 연결 도로를 추가하지 않는다.
- 게임 좌표 범위는 x=145…350, y=258…616. 438개 건물 외곽과 311개 도로 객체를 포함한다.
- 기존 y=422 경계의 벽이 없어져 같은 화면에서 왕복할 수 있다. 실제 주변 지도는 가장자리 밖 60칸까지 배경으로 표시한다. 배경이 보이는 곳까지 전부 이동 가능한 것은 아니다.
- 연세대 정문·성산로 횡단은 다음 구간이다. 북쪽 안내 지점에서 이 범위를 설명한다.
