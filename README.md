# 신촌 모험 · v5

신촌역 2번 출구에서 시작해 연세로·명물길·연세대 정문·백양로와 현대백화점 지하를 탐험하는 도트 게임입니다. 4세대 휴대용 RPG의 선명한 색감과 키 큰 필드 캐릭터 비율을 참고해 캐릭터와 건물을 직접 그렸습니다. 참고 게임의 그래픽 파일은 사용하지 않습니다.

## 실행

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

http://127.0.0.1:8000/ 에 접속합니다. 빌드나 패키지 설치는 필요하지 않습니다. `index.html`을 직접 열어도 동작합니다. 게임 지도와 그래픽은 모두 로컬 파일입니다. Galmuri9 도트 글꼴도 로컬에 포함되어 있습니다.

## 조작

| 동작 | 키 |
| --- | --- |
| 방향 전환 | 방향키 / WASD 짧게 누르기 |
| 걷기 | 방향키 / WASD 길게 누르기 |
| 대화·다음 대사 | E / Space / Enter |
| 계단 입장 | 계단 칸을 밟으면 자동 입장 (E로도 가능) |
| 지도 열기·닫기 | M |
| 지도·대화 닫기 | Esc |
| 달리기 | Shift + 이동 |

한글 IME 상태와 Caps Lock에 영향을 받지 않도록 `KeyboardEvent.code`로 키를 처리합니다. `code`를 제공하지 않는 환경에는 한글 자모 대체 매핑이 있습니다. 화면의 대화·지도 버튼과 터치 방향키도 지원합니다. 방향키는 누른 순간 바라보는 방향만 바뀌며, 약 0.15초 이상 누르면 걷기 시작합니다. 계단 칸에 발을 디디면 곧바로 층이나 장소가 바뀌며, E/Space로 계단을 직접 선택해도 입장할 수 있습니다. 대화·조사는 바로 앞 한 칸의 대상을 바라보고 누릅니다. 빨간 잠망경은 조사 대사만 표시합니다. 터치 방향키도 같으며 새 방향을 누를 때마다 먼저 방향을 전환합니다. 클릭한 버튼과 키보드가 대사를 두 번 넘기지 않도록 키보드 기본 동작을 제어합니다.

## 실제 위치를 반영한 지도

- 지상은 496×712 타일입니다. OpenStreetMap의 큰길·골목·보행로·공원·건물 외곽과 신촌역 출구 좌표를 같은 북쪽 기준 좌표계에 그대로 옮겼습니다. 건물 1,400여 동의 외곽을 1.5m 단위로 살려 골목 모양과 건물 간격이 지도에 더 가깝게 보입니다.
- 북쪽이 위이며 가로·세로 모두 한 타일당 1.5m입니다. 이전의 6m 격자에서 네 배 세분해 실제 보행자와 건물의 크기, 좁은 골목의 꺾임을 맞췄습니다. 현대백화점·U-PLEX·홍익문고·연세대 주요 건물은 실제 외곽을 따라 별도 외관으로 그렸습니다.
- 신촌로가 꺾이는 신촌오거리, 북쪽 연세로, 동북쪽 명물길, 성산로와 연세대 정문·백양로가 이어집니다. 지상에서 연세대로 이동할 때 화면 전환이 없습니다.
- 현대백화점 본관은 역 북서쪽, U-PLEX는 그 북동쪽 연세로 서편, 홍익문고는 3번 출구 북쪽에 표시됩니다.
- 지하 연결은 공식 안내에 맞게 **신촌역 1번 출구 안 ↔ 백화점 B2 ↕ B1 식품관**으로 구현했습니다.
- B2의 지상 출구는 현대백화점 본관과 U-PLEX로 나뉘며, U-PLEX 출구에서 상점 사이 실내 복도를 거쳐 신촌역 대합실로 이동할 수 있습니다. B2에서는 현대백화점 본관의 그라운드 신촌과 U-PLEX의 올리브영을 구분해 표시합니다.
- 신촌역 대합실의 1~8번 출구는 지상 지도에서의 북·동·남·서 방향과 간격을 따라 배치했습니다. 개찰구와 진행 방향이 다른 두 승강장을 넣었으며, 역 내부 세부 통로는 게임용으로 단순화했습니다.
- 백화점 B2·B1 매장 배치도 게임용으로 구성했으며, 실제 실내 평면도나 최신 입점 현황을 복제한 것은 아닙니다.
- M 지도에는 현재 위치, 8개 출구, 북쪽 표시, 100m 축척, 주요 길·장소가 나타납니다. 지하에서는 해당 층의 지도를 보여줍니다.

지도 범위는 신촌역 일대에서 연세대 정문과 백양로 초입까지이며, 범위 밖의 캠퍼스 전체는 포함하지 않습니다. NPC·기념품·대사는 창작입니다.

2026-10-17 [실제 지도 대조 기록](reference/map-audit/README.md): 최신 OSM 출구·주요 지점 14곳과 본관/U-PLEX 외곽을 대조했습니다. 빨잠과 지하 입구 수동 좌표, 출구 중간 반올림, 본관 경계 조각 연결, 과도한 입구 주변 건물 삭제를 수정했습니다. 지점은 마지막 1.5m 격자에서만 반올림하며 실내는 실제 평면도가 아닌 도식입니다.

## 진행과 저장

거리, 역, 백화점 B2, B1, 연세대의 다섯 스탬프를 모으면 완주합니다. 빵집과 캠퍼스 학생의 대화를 끝내면 기념품을 받습니다. 브라우저에 자동 저장하며, v1~v4 저장이 있으면 기존 기념품을 유지하고 새 지도 기준으로 신촌역 2번 출구에서 시작합니다. 다섯 장소 체계에 해당하는 이전 스탬프와 기념품은 유지합니다. ‘새 모험’은 현재 버전의 진행을 초기화합니다.

## 데이터 출처와 라이선스

- **지도 데이터 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0.** `assets/city-geography.js`, `assets/world-data.js`와 `reference/map-data.json`은 이 공개 지도에서 추출·가공한 데이터이며 ODbL 조건을 따릅니다. 신촌 일대 경계: 서 126.932, 동 126.942, 남 37.553, 북 37.563.
- [현대백화점 신촌점 오시는 길](https://www.ehyundai.com/newPortal/DP/WC/WC000000_V.do?branchCd=B00127000): 신촌역 1번 출구 안에서 B2 연결.
- [현대백화점 신촌점 층별 안내](https://www.ehyundai.com/newPortal/DP/FG/FG000000_V.do?branchCd=B00127000&floorIdx=5F): B1 현대식품관·푸드코트.
- [현대백화점 U-PLEX 신촌점 층별 안내](https://ehyundai.com/newPortal/uplex/DP/FG/FG000000_V.do?branchCd=B00127100): U-PLEX B2 올리브영, B1 유스 스트리트.
- [연세대 신촌캠퍼스 오시는 길](https://www.yonsei.kr/sc/502/subview.do): 신촌역 2·3번 출구의 연세대 방향.

`reference/map-data.json`은 공개 배포하는 가공 데이터, `scripts/build-map.py`는 원본 OSM XML에서 추출하는 스크립트입니다. `scripts/build-city.py`는 가공 데이터에서 실제 사용 범위를 잘라 `assets/city-geography.js`를 생성합니다. 실행에는 이 파일을 사용하며 원본 XML과 `assets/world-data.js`는 참고용으로 보존합니다.

지도 데이터 재생성: `python3 scripts/build-city.py`. 원자료는 프로젝트에 보존된 OSM 스냅샷이므로 현재 모든 상호·시설의 상태를 보장하지 않습니다.

- 글꼴: [Galmuri](https://github.com/quiple/galmuri), SIL Open Font License 1.1. 라이선스 전문은 `assets/fonts/OFL.txt`에 포함되어 있습니다.
- 현대백화점 석재 외벽, U-PLEX 유리벽, 빨간 잠망경, 홍익문고와 연세대 정문을 각각 도트로 그렸습니다. 캐릭터와 건물은 모두 코드로 제작한 오리지널 픽셀 아트입니다.
- 화면은 256×192 픽셀로 시작하며 확대 버튼으로 320×240 픽셀의 더 넓은 시야를 볼 수 있습니다. 수첩에서 진행을 확인할 수 있습니다.
