# 신촌 모험 · v4

신촌역 2번 출구에서 시작해 연세로·명물길·연세대 정문·백양로와 현대백화점 지하를 탐험하는 도트 게임입니다. 골드·실버 필드 캐릭터의 작은 비율, 큰 머리, 진한 윤곽선과 방향별 걷기를 참고해 코드로 새 캐릭터를 그렸습니다.

## 실행

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

http://127.0.0.1:8000/ 에 접속합니다. 빌드나 패키지 설치는 필요하지 않습니다. `index.html`을 직접 열어도 동작합니다. 게임 지도와 그래픽은 모두 로컬 파일입니다. Galmuri9 도트 글꼴도 로컬에 포함되어 있습니다.

## 조작

| 동작 | 키 |
| --- | --- |
| 방향 전환 | 방향키 / WASD 짧게 누르기 |
| 걷기 | 방향키 / WASD 길게 누르기 |
| 대화·출입·다음 대사 | E / Space / Enter |
| 지도 열기·닫기 | M |
| 지도·대화 닫기 | Esc |
| 달리기 | Shift + 이동 |

한글 IME 상태와 Caps Lock에 영향을 받지 않도록 `KeyboardEvent.code`로 키를 처리합니다. `code`를 제공하지 않는 환경에는 한글 자모 대체 매핑이 있습니다. 화면의 대화·지도 버튼과 터치 방향키도 지원합니다. 방향키는 누른 순간 바라보는 방향만 바뀌며, 약 0.15초 이상 누르면 걷기 시작합니다. 대화·조사는 바로 앞 한 칸의 대상을 바라보고 누르며, 계단은 앞에서 바라보거나 계단 위에서 사용할 수 있습니다. 빨간 잠망경은 조사 대사만 표시합니다. 터치 방향키도 같으며 새 방향을 누를 때마다 먼저 방향을 전환합니다. 클릭한 버튼과 키보드가 대사를 두 번 넘기지 않도록 키보드 기본 동작을 제어합니다.

## 실제 위치를 반영한 지도

- 지상은 124×178 타일입니다. OpenStreetMap의 도로·공원·건물 구획과 신촌역 출구 좌표를 한 좌표계로 변환했습니다.
- 북쪽이 위이며 가로·세로 모두 한 타일당 약 6m입니다. 도로 폭과 건물 외곽은 타일에 맞춰 단순화했습니다. 일반 건물은 실제 구획 안에 들어가는 직사각형으로 표현하고, 작은 건물은 생략합니다.
- 신촌로가 꺾이는 신촌오거리, 북쪽 연세로, 동북쪽 명물길, 성산로와 연세대 정문·백양로가 이어집니다. 지상에서 연세대로 이동할 때 화면 전환이 없습니다.
- 현대백화점 본관은 역 북서쪽, U-PLEX는 그 북동쪽 연세로 서편, 홍익문고는 3번 출구 북쪽에 표시됩니다.
- 지하 연결은 공식 안내에 맞게 **신촌역 1번 출구 안 ↔ 백화점 B2 ↕ B1 식품관**으로 구현했습니다.
- B2의 지상 출구는 현대백화점 본관과 U-PLEX로 나뉘며, 각각 해당 건물 앞 거리로 이어집니다.
- 지하 각 매장·개찰구의 세부 배치는 게임용입니다. 실제 실내 평면도 또는 최신 입점 현황을 복제한 것은 아닙니다.
- M 지도에는 현재 위치, 8개 출구, 북쪽 표시, 100m 축척, 주요 길·장소가 나타납니다. 지하에서는 해당 층의 지도를 보여줍니다.

지도 범위는 신촌역 일대에서 연세대 정문과 백양로 초입까지이며, 범위 밖의 캠퍼스 전체는 포함하지 않습니다. NPC·기념품·대사는 창작입니다.

## 진행과 저장

거리, 역, 백화점 B2, B1, 연세대의 다섯 스탬프를 모으면 완주합니다. 빵집과 캠퍼스 학생의 대화를 끝내면 기념품을 받습니다. 브라우저에 자동 저장하며, v1~v3 저장이 있으면 기존 기념품을 유지하고 변경된 지도에 맞춰 신촌역 2번 출구에서 시작합니다. 다섯 장소 체계에 해당하는 이전 스탬프와 기념품은 유지합니다. ‘새 모험’은 현재 버전의 진행을 초기화합니다.

## 데이터 출처와 라이선스

- **지도 데이터 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0.** `assets/city-geography.js`, `assets/world-data.js`와 `reference/map-data.json`은 이 공개 지도에서 추출·가공한 데이터이며 ODbL 조건을 따릅니다. 신촌 일대 경계: 서 126.932, 동 126.942, 남 37.553, 북 37.563.
- [현대백화점 신촌점 오시는 길](https://www.ehyundai.com/newPortal/DP/WC/WC000000_V.do?branchCd=B00127000): 신촌역 1번 출구 안에서 B2 연결.
- [현대백화점 신촌점 층별 안내](https://www.ehyundai.com/newPortal/DP/FG/FG000000_V.do?branchCd=B00127000&floorIdx=5F): B1 현대식품관·푸드코트.
- [연세대 신촌캠퍼스 오시는 길](https://www.yonsei.kr/sc/502/subview.do): 신촌역 2·3번 출구의 연세대 방향.
- [골드·실버 캐릭터 참고](https://bulbapedia.bulbagarden.net/wiki/Gold_(game)#Game_assets). 참고 이미지는 게임 실행에 사용하지 않습니다.

`reference/map-data.json`은 공개 배포하는 가공 데이터, `scripts/build-map.py`는 원본 OSM XML에서 추출하는 스크립트입니다. `scripts/build-city.py`는 가공 데이터에서 실제 사용 범위를 잘라 `assets/city-geography.js`를 생성합니다. 실행에는 이 파일을 사용하며 원본 XML과 `assets/world-data.js`는 참고용으로 보존합니다.

지도 데이터 재생성: `python3 scripts/build-city.py`. 원자료는 프로젝트에 보존된 OSM 스냅샷이므로 현재 모든 상호·시설의 상태를 보장하지 않습니다.

- 글꼴: [Galmuri](https://github.com/quiple/galmuri), SIL Open Font License 1.1. 라이선스 전문은 `assets/fonts/OFL.txt`에 포함되어 있습니다.
- 현대백화점 석재 외벽, U-PLEX 유리벽·전광판, 빨간 잠망경, 홍익문고와 연세대 정문을 각각 도트로 그렸습니다. 캐릭터와 건물은 코드로 제작했으며 참고 게임의 이미지를 실행 자산으로 사용하지 않습니다.
- 화면은 208×176 픽셀로 시작하며 축소 버튼으로 256×208 픽셀의 더 넓은 시야를 볼 수 있습니다. 수첩에서 진행을 확인할 수 있습니다.
