# 회전하는 신촌 — 야외 구간 01–06

`prototype/index.html`을 HTTP(S)로 실행한다. Three.js 0.160.1(MIT)을 로컬 제공하며, 현재 제공되는 유일한 게임이다. 사이트 루트에서도 이 게임으로 연결된다.

## 현재 구현

- 저장된 `CITY_GEOGRAPHY`의 실제 도로·건물 외곽을 일정 비율로 축소한 연속 좌표 지도다. 신촌역·현대백화점·U-PLEX부터 연세로, 명물길, 성산로 횡단보도, 연세대 정문, 백양로, 캠퍼스 북쪽, 신촌역로 연결부까지 6개 구간과 18개 방문 지점을 제공한다.
- 상세화 영역은 24개다. 현대백화점 본관과 U-PLEX는 출처가 있는 지상 12층·높이 정보를 반영했다. 다른 건물의 높이와 외관은 대부분 예시이며 추가 확인이 필요하다. 일반 상가는 공용 텍스처를 재사용한다.
- 저장된 OSM 건물 연결교(1041227528)의 하부 높이를 반영해 현백–U-PLEX 사이 지상 골목을 통과할 수 있다. 이 통로는 지하 연결통로나 4층 실내 입구가 아니다. 지하철·백화점 실내는 아직 제공하지 않는다.
- 캐릭터는 사용자 승인 과잠 디자인의 `assets/varsity-atlas.png`를 `avatar.mjs`로 그린다. 20개 포즈를 24×32 캔버스에 최근접 보간으로 출력한다. 출처는 `assets/varsity-character.md`에 기록했다.

## 입력과 시점

- 방향키/WASD: 짧게 누르면 바라보기, 150ms 이상 누르면 걷기. 대각선 속도는 정규화한다.
- 누르는 동안 이동 방향은 입력 시작 시점 기준으로 유지한다. 키를 놓았다 다시 누르면 현재 화면 기준을 적용한다. 도로 자동 조향은 없다.
- Shift 또는 달리기 버튼: 걷기 4.1, 달리기 7.4의 속도로 이동한다. 터치 입력은 포인터 캡처와 텍스트 선택 방지를 사용한다.
- Space/E: 장소 살펴보기. M: 북쪽 기준 지도. Z: 화면 거리 변경.
- `OcclusionCamera`만 사용한다. 기본은 북쪽 정면 고정이다. 건물이 캐릭터 몸·머리 또는 바로 앞을 0.45초 이상 가리면 좌우 20°/35° 후보를 비교해 가림이 줄어드는 쪽으로 회전한다. 정면이 1초 이상 열리면 복귀한다. 회전 속도와 재전환 대기시간을 제한한다.
- U-PLEX 동쪽 전면·북쪽 빨잠 광장(측량 좌표 x215–255, y430–485)은 요청에 따라 가림 발생 시 −20°로 회전한다. 남는 가림은 건물 투명 처리와 캐릭터 우선 표시로 보완한다.
- Q/R: 수동 회전. C: 자동 보정 전환. 역 앞으로: 위치·시점 초기화.
- 이동 충돌은 작은 연속 단계로 검사해 건물 관통을 방지하고 벽을 따라 미끄러지도록 한다.

## 검증

저장소 루트에서 `node tests/prototype.test.mjs` 실행. 전체 방문 지점 도달 가능성, 구간 간 왕복 보행, 연결교 하부 통과, 건물 충돌, 입력 유지와 재입력, 달리기, 캐릭터 프레임, 가림 보정 지연·복귀·수동 조작, 유플렉스 반대 회전을 검사한다.

지도 출처와 구간별 조사 내역은 `reference/map-audit/`에 있다. 폐기된 도로 추종 카메라와 자동 조향 구현은 Git 이력에서 확인할 수 있다.
